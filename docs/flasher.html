Warped Pinball Vector — USB Flasher

Update your Vector board straight from this page over a USB cable — no downloads, no drivers.

Works on desktop computers only (Chrome, Edge, Brave, or Opera). Phones and tablets aren't supported.

← Back to the firmware changelog

This flasher only works on desktop computers

Before you start

  • Turn off your pinball machine. You do not need to remove the Vector board.
  • Connect the board to this computer with a data USB cable (some cables are charge-only).
  • Connect one board at a time.
  • When prompted, grant the browser permission to access the USB / serial device. The browser asks once for the running board and once for the bootloader — this is normal and only happens the first time.

1. Connect

Plug the board in (machine powered off) and detect what it is.

— —
Couldn’t detect this board’s game series. Choose it manually below. ⚠️ Selecting the wrong series flashes firmware that drives the wrong signals and can permanently damage your pinball machine. Only continue if you are certain which series this board is for — if unsure, stop and ask for help.

Erase & flash firmware

Wipes the board with nuke.uf2 and installs the firmware (OS) image for the detected model. Use this when changing game series or recovering a board.

This happens in two steps so each can be confirmed on its own:

  1. Reset the board into its bootloader and confirm it’s detected.
  2. Erase and write the firmware image.

Already holding BOOTSEL / board stuck? You can still click “Enter bootloader mode” — it will detect a board that’s already in the bootloader.

Update software

Installs the Warped Pinball application over serial onto a running board. No erase, no bootloader — use this for a normal version update.

Serial monitor

Watch the board’s serial output (print() statements and the REPL) live. Stop the monitor before flashing or updating — only one connection to the board can be open at a time.
