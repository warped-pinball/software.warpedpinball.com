Before you start

  • Turn off your pinball machine. You do not need to remove the Vector board.
  • Connect the board to this computer with a data USB cable (some cables are charge-only).
  • Connect one board at a time.
  • When prompted, grant the browser permission to access the USB / serial device. The browser asks once for the running board and once for the bootloader — this is normal and only happens the first time.

    Board not detected? Manual recovery (BOOTSEL)

    If the board can’t be reset automatically, you can put it into the bootloader by hand:

    1. Unplug the board’s USB cable.
    2. Press and hold the BOOTSEL button on the Pico.
    3. While holding it, plug the USB cable back in, then release the button.
    4. Click Update my Vector again and choose the device when prompted.

    If nothing shows up at all, try a different USB cable — many cables only carry power, not data.
